VLAN چیست و چرا در شبکه استفاده می‌شود؟

VLAN یکی از مهم‌ترین مفاهیم در طراحی شبکه‌های سازمانی است. در این مقاله با مفهوم VLAN، کاربرد آن، تفاوت Access و Trunk و یک سناریوی واقعی از تقسیم‌بندی شبکه آشنا می‌شویم.

📚 سطح: متوسط ⏱ زمان مطالعه: 8 دقیقه 🏷 دسته‌بندی: Switching ✦ AJORLOO•TECH

VLAN چیست؟

VLAN مخفف Virtual Local Area Network است. VLAN به ما اجازه می‌دهد یک شبکه فیزیکی را به چند شبکه منطقی مستقل تقسیم کنیم.

به زبان ساده، ممکن است شما فقط یک یا چند سوئیچ فیزیکی داشته باشید، اما با استفاده از VLAN می‌توانید کاربران، سرورها، دوربین‌ها، تلفن‌های VoIP و سایر تجهیزات را در شبکه‌های منطقی جداگانه قرار دهید.

نکته مهم: VLAN باعث ایجاد جداسازی منطقی در لایه 2 می‌شود. برای برقراری ارتباط بین VLANهای مختلف معمولاً به Routing یا یک دستگاه Layer 3 نیاز داریم.

چرا از VLAN استفاده می‌کنیم؟

یکی از دلایل اصلی استفاده از VLAN، کنترل بهتر ساختار شبکه و جداسازی Broadcast Domainها است.

برای مثال فرض کنید در یک شرکت این تجهیزات را داریم:

  • کامپیوترهای کاربران
  • سرورهای سازمان
  • دوربین‌های IP
  • تلفن‌های VoIP
  • Guest Wi-Fi

به جای اینکه همه تجهیزات در یک شبکه قرار بگیرند، می‌توانیم برای هر گروه یک VLAN جدا تعریف کنیم.

یک سناریوی ساده

VLAN کاربرد Network
10 Users 192.168.10.0/24
20 Servers 192.168.20.0/24
30 CCTV 192.168.30.0/24
40 VoIP 192.168.40.0/24
50 Guest Wi-Fi 192.168.50.0/24

Access Port چیست؟

یک Access Port معمولاً برای اتصال End Deviceها استفاده می‌شود؛ مانند کامپیوتر، پرینتر، دوربین یا برخی تجهیزات دیگر.

در یک سناریوی ساده، اگر پورت شماره 10 روی VLAN 30 قرار گرفته باشد، دوربین متصل به آن پورت عضو VLAN 30 خواهد بود.

interface GigabitEthernet0/10 switchport mode access switchport access vlan 30

Trunk Port چیست؟

Trunk Port برای انتقال چند VLAN از یک لینک استفاده می‌شود. این نوع پورت معمولاً در ارتباط بین سوئیچ‌ها، سوئیچ و روتر یا سوئیچ و برخی تجهیزات زیرساختی استفاده می‌شود.

در این حالت فریم‌ها معمولاً با VLAN Tag منتقل می‌شوند تا دستگاه مقصد بتواند VLAN مربوط به هر فریم را تشخیص دهد.

interface GigabitEthernet0/24 switchport mode trunk switchport trunk allowed vlan 10,20,30,40,50

تفاوت Access و Trunk

ویژگی Access Trunk
تعداد VLAN معمولاً یک VLAN چند VLAN
کاربرد معمول End Device Switch-to-Switch
VLAN Tagging معمولاً بدون Tag در سمت End Device برای VLANهای مختلف
مثال PC / Printer / Camera Uplink / Switch

یک نکته مهم در پروژه‌های واقعی

در شبکه‌های واقعی، تعریف VLAN به تنهایی کافی نیست. باید طراحی IP، Routing، DHCP، ACL و سیاست‌های امنیتی نیز در کنار آن در نظر گرفته شوند.

برای مثال ممکن است VLAN دوربین‌ها اجازه دسترسی مستقیم به VLAN کاربران را نداشته باشد، اما NVR بتواند به دوربین‌ها دسترسی داشته باشد.

همین موضوع باعث می‌شود VLAN یکی از ابزارهای مهم برای طراحی یک زیرساخت مرتب، قابل مدیریت و قابل توسعه باشد.

اشتباهات رایج هنگام کار با VLAN

  1. قرار دادن پورت End Device در VLAN اشتباه
  2. عدم تطابق VLANهای Allowed روی دو طرف Trunk
  3. اشتباه در Native VLAN
  4. تعریف نشدن Gateway مناسب برای VLAN
  5. فراموش کردن DHCP Scope مربوط به VLAN جدید
  6. وجود ACL یا Firewall Rule که ارتباط موردنظر را مسدود می‌کند

روش پیشنهادی برای عیب‌یابی

وقتی یک سیستم بعد از ایجاد VLAN ارتباط ندارد، بهتر است مرحله‌به‌مرحله جلو برویم و فقط حدس نزنیم.

  1. بررسی کنیم کابل و Link Up هستند.
  2. VLAN پورت را بررسی کنیم.
  3. در صورت استفاده از Trunk، VLANهای مجاز را بررسی کنیم.
  4. IP و Subnet Mask را بررسی کنیم.
  5. Gateway را بررسی کنیم.
  6. DHCP را بررسی کنیم.
  7. Routing بین VLANها را بررسی کنیم.
  8. در نهایت ACL و Firewall را بررسی کنیم.

جمع‌بندی

VLAN یکی از پایه‌های اصلی طراحی شبکه‌های مدرن است. با استفاده صحیح از VLAN می‌توان شبکه را به بخش‌های منطقی تقسیم کرد، Broadcast Domainها را کنترل کرد و مدیریت زیرساخت را ساده‌تر کرد.

اما طراحی VLAN باید بخشی از یک معماری کامل شبکه باشد. Routing، امنیت، IP Addressing، DHCP و مانیتورینگ همگی در کنار VLAN اهمیت دارند.

تجربه عملی: در پروژه‌های سازمانی، قبل از ساخت VLANهای جدید بهتر است ساختار IP Addressing، نیازهای Routing و مسیرهای ارتباطی بین سرویس‌ها از ابتدا مشخص شوند. این کار از بسیاری از مشکلات بعدی جلوگیری می‌کند.
